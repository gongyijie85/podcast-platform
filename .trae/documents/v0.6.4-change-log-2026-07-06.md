# v0.6.4 变更日志

## 版本信息
- 版本号：0.6.4
- 修改时间：2026-07-06（上海时间）
- 变更主题：主播口播稿提示词优化

## 背景
针对英文原著（如 ISBN 9780375811746《Flipped》）生成主播口播稿时，出现以下问题：
1. 中英混杂，中间插入英文原文。
2. 内容截断，句子不完整。
3. 直接使用英文书名《Flipped》，未使用中文书名《怦然心动》。
4. 提示词未明确要求基于中文简介生成内容。

## 修改内容

### 1. 提示词模板优化
**文件**：`backend/src/modules/book/prompts/live-pitch.template.ts`

- `LIVE_PITCH_SYSTEM_PROMPT`：
  - 明确要求**全中文输出**，禁止英文书名、作者名或原文引用。
  - 强制使用用户提供的中文书名。
  - 规范结构：开场钩子 → 内容亮点 → 适合人群 → 行动号召。
  - 字数 150-250 字，要求语义完整、不截断。

- `LIVE_PITCH_USER_TEMPLATE`：
  - 优先读取 `titleZh` / `authorZh` / `publisherZh` / `summaryZh` 中文字段。
  - 中文字段缺失时 fallback 到英文原字段，保证兼容性。

### 2. Mock 兜底模板优化
**文件**：`backend/src/modules/book/live-pitch.service.ts`

- `mockGenerate` 方法优先使用中文翻译字段生成兜底文案。
- 避免在无 LLM key 的 dev 环境下输出中英混杂的口播稿。
