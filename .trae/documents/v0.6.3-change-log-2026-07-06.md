# v0.6.3 变更日志

## 版本信息
- 版本号：`0.6.3`
- 修改时间：2026-07-06（上海时间）
- 变更范围：backend / frontend / database / tests

## 主要目标
对英文图书的扫码/封面识别结果提供中文翻译，并将翻译结果持久化到书库，避免重复调用 LLM。

## 关键变更

### 后端
1. `backend/src/modules/book/translation.service.ts`（新增）
   - 封装 OpenAI 兼容 LLM 翻译服务。
   - 输入：`title`、`author`、`publisher`、`summary`。
   - 输出：`titleZh`、`authorZh`、`publisherZh`、`summaryZh`。
   - 120 秒超时，支持非标准 JSON 解析。

2. `backend/src/modules/book/book-library.service.ts`
   - 新增 `updateTranslation(isbn, translation)`：将中文翻译写入 `BookLibraryItem`。
   - `toDto` 和 `upsertOne` 暴露/更新中文字段。

3. `backend/src/modules/book/book.controller.ts`
   - `POST /books/cover/recognize`：候选图书并行翻译并缓存。
   - `GET /books/library/:isbn`：详情页优先返回缓存中文翻译，未命中时翻译并落库。

4. `backend/prisma/schema.prisma`
   - `BookLibraryItem` 新增 `titleZh`、`authorZh`、`publisherZh`、`summaryZh`。

### 前端
1. `frontend/src/pages/ScanCover.tsx`
   - 候选卡片优先展示中文书名、作者、出版社；英文原名作为副标题保留。

2. `frontend/src/pages/BookDetail.tsx`
   - 详情页标题、作者、出版社、简介优先展示中文，英文原样保留。

3. `frontend/vitest.config.ts`
   - `react-router` / `react-router-dom` alias 改为动态 `require.resolve`，修复 pnpm 依赖结构变化导致的测试解析失败。

### 测试
- `backend/test/book.controller.cover-search.spec.ts`
- `backend/test/book.controller.cover-resolve.spec.ts`
  - 补充 `TranslationService` mock，修复测试构建失败。
