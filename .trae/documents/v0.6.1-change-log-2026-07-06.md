# v0.6.1 变更日志

## 基本信息
- 版本号：0.6.1
- 修改时间：2026-07-06（上海时间）
- 变更主题：前端三端（电脑 / 手机 / 平板）响应式布局优化

## 修改文件清单

### 断点与布局
- `frontend/src/hooks/useMediaQuery.ts`
  - 自定义断点与 MUI 默认断点对齐（xs: 0-599, sm: 600-899, md: 900-1199, lg: 1200+）
  - 新增 `useIsCompact()`，用于宽度小于 900px 的紧凑布局判断
- `frontend/src/layouts/MainLayout.tsx`
  - 引入 `useTablet()`，平板自动折叠侧边栏
  - 移动端 sidebar 使用 temporary drawer，桌面/平板使用 persistent sidebar

### 页面响应式调整
- `frontend/src/pages/BookDetail.tsx`
  - 栅格改为 `xs={12} lg={6}`，电脑端左右分栏，移动端/平板单栏堆叠
  - 封面图片响应式：`maxWidth: { xs: 160, sm: 200 }`，移动端居中、桌面端左对齐
  - 生成/保存按钮：`direction: { xs: 'column', sm: 'row' }`，移动端占满宽度
- `frontend/src/pages/ProjectDetail.tsx`
  - 项目标题加 `wordBreak: 'break-word'`，防止长标题溢出
  - BGM 卡片栅格：`xs:1fr / sm:2列 / lg:3列`
  - 下载按钮区域响应式堆叠 + `flexWrap="wrap"`
- `frontend/src/pages/ScanCover.tsx`
  - 拍照按钮移动端 `fullWidth`，桌面端自适应宽度
  - 候选图书卡片：`xs:column / sm:row`，移动端封面更大（120×160）、信息垂直展示
- `frontend/src/pages/Dashboard.tsx`
  - 移动端"新建项目"按钮占满宽度
- `frontend/src/pages/Projects.tsx`
  - 调整栅格列数，避免平板设备卡片过密
- `frontend/src/features/book-organizer/BookOrganizer.tsx`
  - 筛选区两栏断点从 lg 调整为 md
  - 指标卡片响应式最小高度
  - 操作按钮 `xs:column / md:row`
- `frontend/src/components/book/BookCard.tsx`
  - 列表模式移动端改为垂直布局，提升小屏可读性
